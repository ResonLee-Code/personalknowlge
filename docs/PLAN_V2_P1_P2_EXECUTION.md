## 3. Sync 2.0

### 3.1 核心边界

- [x] 传输 trait 与 WebDAV / S3 兼容适配器；不接入任何厂商托管云。
- [x] 凭据只写入应用数据目录，不进入工作区、Markdown、备份或日志。
- [x] 正文、附件、索引缓存分别选择端到端加密；远端对象名与内容不泄露明文标题。
- [x] manifest 带版本、设备、内容哈希和删除墓碑；只做可验证的对象同步。
- [x] 离线队列持久化，退出重启后继续；关闭同步不影响所有本地能力。

### 3.2 冲突与预览

- [x] dry-run 返回上传、下载、删除、冲突计数与逐文件原因。
- [x] 新增、修改、删除、冲突四场景可自动复现。
- [x] 三方合并在无重叠修改时自动完成；重叠修改进入人工选择。
- [x] 冲突界面保留本地/远端/共同祖先，任意选择都不丢另一版本。
- [x] 每次成功覆盖 / 删除前保存可恢复历史版本；失败保留本地原件。

### 3.3 自动门禁

- [x] 本地 WebDAV 桩覆盖实际使用的 GET/PUT/MKCOL、认证、ETag 与 manifest 并发保护。
- [x] 首次 profile / manifest 使用条件创建；两个并发初始化者只有一个能成功，另一个重新读取。
- [x] 凭据原子私有写入，Unix 创建即 `0600`，替换时不跟随预置符号链接；明文 HTTP 的本机
  判定只接受解析后的真实回环地址，`127.evil.com` 一类公网主机不能绕过 HTTPS 要求。
- [x] S3 兼容适配器用本地 HTTP 桩跑通 GET/PUT、条件 manifest 与 SigV4 请求生成。
- [x] 密文验收：远端字节不包含正文、标题、附件内容等已知明文标记。
- [x] 两台逻辑设备共享本地远端桩，逐步跑完新增 / 修改 / 删除 / 冲突 / 合并。
- [x] 篡改 manifest、错误口令与网络离线必须被拒绝或进入重试队列，且不清空本地数据。

### 3.4 人工验收

- [ ] 至少一个真实 WebDAV 和一个 S3 兼容服务完成 dry-run、双向同步与冲突选择。
- [ ] 两台真实设备验证网络中断、恢复、时钟偏差和删除传播。

## 5. Writing

### 5.1 生成与引用

- [x] 大纲、续写、改写、缩短、扩写共用一条服务契约。
- [x] 每个生成段落都绑定可解析引用；未知编号、越界区间或过期来源使整段失效。
- [x] 复用 Ask 的检索预算、在线→本地→模板路由、外发确认和审计。
- [x] 生成只返回草稿，不直接调用保存命令。

### 5.2 逐段审查

- [x] diff 预览明确显示新增、删除和替换；未预览前确认写入按钮禁用。
- [x] 逐段接受 / 拒绝，可由用户组装最终草稿。
- [x] 接受前重新校验来源区间与目标笔记哈希；冲突时禁止覆盖。
- [x] 用户最终确认后才写入；保存走现有历史留档，可恢复上一版。

### 5.3 自动与人工门禁

- [x] Rust 覆盖五种模式、引用正负路径、预算拒绝、来源漂移和哈希冲突。
- [x] 前端覆盖逐段选择、diff、取消不写、失败可点开原因。
- [x] 使用 DeepSeek 与 `qwen2.5:7b` 分别完成五种写作模式，所有草稿段落均有可解析引用
      （[证据](./acceptance/V2_WRITING_LIVE_MODELS_20261023.md)）。
- [x] 未授权真实 DeepSeek 的 Writing 调用经系统级 `nettop` 验证零 TCP，并降级模板

- [ ] 人工使用真实模型评估结构、语气、引用准确性；逐段编辑体验需真机确认。
