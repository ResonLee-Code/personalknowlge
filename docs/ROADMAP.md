## 当前状态

- **已发布版本**：V1.0.1（2026-10-07，macOS 已构建；Windows 待确认后同步）
- **已完成阶段**：Phase 0–5（技术验证 → 稳定性），详见下方各段

> 按当前约定，跨平台产物更新需要先确认版本，再执行重新打包与真机验收。

## 已确认的执行口径（2026-10-07）

| 决策 | 结果 |
| --- | --- |
| Windows 打包 | 等待更新指令，不自动打包（`dist-windows/` 保持 V1.0.0） |

| 知识图谱 | 先交付 M1（双链地基）、M2（编辑体验），M3 图谱视图后续评估 |

## 已知限制

1. 文件监听在受限环境下降级为 3 秒轮询，首次同步可能有短暂延迟；
2. 中文索引体积约为正文的 2~3 倍（单字 + 双字扩展）；
3. 未做多窗口协同编辑；同一文件的并发写入依赖哈希冲突检测而非实时锁；
4. 版本历史、撤销历史未持久化（V1.0 范围外）。
