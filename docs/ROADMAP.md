## 已知限制

1. 文件监听在受限环境下降级为 3 秒轮询，首次同步可能有短暂延迟；
2. 中文索引体积约为正文的 2~3 倍（单字 + 双字扩展）；
3. 未做多窗口协同编辑；同一文件的并发写入依赖哈希冲突检测而非实时锁；
4. 版本历史已持久化（`.knowledge/history/`，V1.2.1 交付：60 秒节流、每篇 50 份）；
   编辑器内的撤销/重做历史仍是会话级，不跨重启；
5. ~~同一工作区内的扫描与文件监听并发可能触发 `UNIQUE constraint` 冲突~~
   **已解决（V1.2.1 阶段 B）**：两条采纳路径在事务内幂等、`create` 也改为幂等落库，
   `tests/concurrency_scan_flow.rs` 三项并发用例 + 3000/10000 篇基准回归通过；
   唯一残留的理论窗口是「扫描恰好在 `create` 写文件与插行之间的微秒级间隔内完成采纳」，
   此时 `create` 沿用已有行而非失败（已由测试覆盖）。
