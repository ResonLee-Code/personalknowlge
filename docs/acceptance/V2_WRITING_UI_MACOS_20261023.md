## 发现并修复的缺陷

原实现把写作段落直接拼在笔记末尾。笔记若以代码围栏 ` ``` ` 结尾，会生成：

```text
```- 新段落 [1]
```

导致后续 Markdown 和 Mermaid 全部被误当作代码块内容。

修复后，块级写作结果与前后正文之间至少保留一个空行；无论插入点位于代码围栏之后、
正文中间还是文末，都不会紧贴非空文本。

回归测试：

- `applying_after_a_closing_fence_keeps_a_block_boundary`
- 修复前失败，修复后通过。
