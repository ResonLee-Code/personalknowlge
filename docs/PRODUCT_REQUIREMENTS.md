# 产品需求与验收状态

对应设计文档第 4 / 5 / 26 章。实现状态以本仓库代码与测试为准。

## 1. 产品定义

Personal Knowledge OS 是面向个人长期知识积累的跨平台桌面知识管理软件。
V1.0 只做三件事：**记录、分类、搜索**，同时保证数据自主、可备份、可扩展。

产品原则：本地优先 / 用户拥有数据 / 先解决核心问题 / 简单而强大 / 可恢复。

## 3. 非功能需求

| 领域 | 目标 | 现状 |
| --- | --- | --- |
| 性能 | 常规搜索 < 500ms；搜索结果首屏 ≤ 50 条 | 列表分页 1–500，搜索每页 1–100，默认 50；索引更新不阻塞编辑器（后台线程） |
| 可靠性 | 保存失败不覆盖原文件；索引可重建；删除可恢复 | 原子写入 + FTS5 重建 + 回收站 |
| 安全 | 不上传内容；限制在工作区内；不执行笔记脚本 | 无网络调用；路径穿越校验；预览不渲染原始 HTML |
| 可维护性 | TS strict、Rust 明确错误类型、迁移管理、UI 不直连数据库 | 见 `docs/DEVELOPMENT_RULES.md` |

## 5. V1.0 明确不做（与设计文档 4.2 一致）

AI 问答、向量数据库、语义搜索、云同步、账号体系、多用户协作、移动端、插件市场、
所见即所得编辑器、自动知识图谱、自动摘要、自动标签、在线分享、订阅系统。

## 6. 成功标准

> 用户愿意每天使用它记录知识，并且在未来需要时能够快速找回曾经记录的内容。

因此本版本重点保证：记录路径足够短（⌘N → 输入 → 自动保存）、
找回路径足够快（⌘K → 中文关键词 → 高亮摘要 → 打开笔记）、
数据足够安全（Markdown + 回收站 + 可校验备份）。
