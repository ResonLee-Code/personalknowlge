# Personal Knowledge OS 使用说明手册（逐控件）

> 面向**使用者**。这本手册按"屏幕 → 区域 → 控件"逐条讲清楚：**它是什么、点下去会怎样、什么时候用它**。
> 与 [GUIDE.md](./GUIDE.md) 的分工：指南按"任务"讲（怎么上手、怎么排错），
> 手册按"控件"讲（每个按钮/输入框/菜单项各是干什么的）。
>
> 适用版本 **V1.3.1**（界面以 `main` 为准，2026-10-19）。界面文案就是控件名，照名字找即可。

---

## 1. 窗口总览

```text
┌────────────────────────────────────────────────────────────────┐
│ 顶栏：知识库名 · 全局搜索(⌘K) · 保存状态 · 主题 · 设置          │
├──────────┬──────────────────────┬──────────────────────────────┤
│ 侧边栏    │ 笔记列表栏            │ 编辑器 / 预览                 │
│ 导航 11 项 │ 标题+篇数 · 大纲开关  │ 工具栏 · 正文 · 关系 · 反向链接 │
│ 分类 · 标签│ 筛选 · 排序 · 条目    │ （大纲可放这一栏，也可钉到右边）│
├──────────┴──────────────────────┴──────────────────────────────┤
│ 状态栏：索引状态 · 笔记/分类/标签数 · 当前列表条数 · 运行模式     │
└────────────────────────────────────────────────────────────────┘
```

- **三栏都能拖**：把鼠标放到栏与栏之间的分隔条上拖动；双击分隔条**复位**，方向键可微调。
- 侧边栏宽度、列表宽度、编辑器分屏比例**随工作区记住**；关掉重开还在原来的样子。
- 窗口大小与位置也记住；若上次的位置已经不在任何屏幕上（比如拔了外接屏），只恢复尺寸。

## 2. 顶栏（高 48px）

| 控件 | 位置 | 作用 |
| --- | --- | --- |
| **知识库名** | 左 | 当前打开的知识库；右边灰字是它的目录。鼠标悬停看完整路径 |
| **全局搜索** | 中偏左 | 点它或按 `⌘/Ctrl + K` 打开搜索面板：标题 / 正文 / 标签一起搜，带过滤器与高亮 |
| **保存状态** | 搜索框右边 | `已保存` / `保存中…` / `未保存`；`已保存（检索索引待重建）` 表示正文已写盘、检索里暂时搜不到（悬停看原因）。2026-10-17 起它紧挨搜索框，不再贴在最右 |
| **收藏 / 移动分类 / 更多操作** | 右 | **打开着笔记时**才出现（2026-10-17 从编辑器工具栏搬上来）：收藏（收藏后橙色实心）、移动分类、更多操作（重命名 / 创建副本 / 历史版本 / 来源与时效 / 复制路径 / 在文件夹中显示 / 另存为模板 / 导出 / 移到回收站；回收站里的笔记则是恢复 / 永久删除） |
| **主题** | 右 | 一键在浅色 / 深色之间切换；选择记在工作区设置里 |
| **设置** | 右 | 打开设置页（**设置只有这一个入口**；侧边栏里那个已删掉，避免两个入口） |

> 顶栏左侧**没有**侧边栏开关：侧边栏的收起 / 展开在侧边栏自己身上（见下一节）。

## 3. 侧边栏

侧边栏有两个形态：**展开态**（默认，248px 起）与**图标栏态**（收起后 44px）。

### 3.1 展开态

| 控件 | 作用 |
| --- | --- |
| **工作区切换**（顶部） | 展开当前 / 最近打开的知识库列表；可切换、打开已有目录、新建知识库 |
| **新建笔记** | 打开新建笔记对话框（也可按 `⌘/Ctrl + N`） |
| **导航 11 项** | 见下方逐项说明；右侧数字是该项的条目数 |
| **分类**（区块标题） | **点标题可以折叠 / 展开这一块**；右侧 `+` 新建分类 |
| **标签**（区块标题） | 同上：点标题折叠，右侧 `+` 新建标签 |
| **重新扫描** | 让应用重新读一遍工作区目录：采纳外部新增 / 修改的文件，标记被删掉的（外部改动太多时用它） |
| **收起侧边栏**（左下角） | 把侧边栏收成 44px 图标栏。**它和展开态的展开按钮在同一高度**，收起 / 展开时不用重新找 |

导航项逐条：

| 导航项 | 去哪里 | 说明 |
| --- | --- | --- |
| 首页 | `/` | 统计与待办（待复核卡片在首页） |
| 全部笔记 | `/notes` | 所有笔记；可筛选、排序、多选、拖拽排目录 |
| Inbox | `/inbox` | 没归类的笔记（把笔记拖到这一项上 = 移出分类） |
| 收藏 | `/favorites` | 标了星标的笔记 |
| 知识图谱 | `/graph` | 双向链接画成图：拖拽、缩放、1–2 跳聚焦 |
| 研究助手 | `/research` | 立项 → 收集 → 验证 → 汇总 → 写入提案（默认被 AI 闸门挡住） |
| 附件 | `/attachments` | 按月份清点图片附件，显示引用笔记，可筛「只看未引用」 |
| 目录管理 | `/manage` | 全部文档的宽表：层级、分类、时间、字数一览与批量整理 |
| 分类 | `/categories` | 分类的增删改（与磁盘目录一一对应） |
| 标签 | `/tags` | 标签的增删改与计数 |
| 回收站 | `/trash` | 删掉的笔记：恢复 / 永久删除（回收站是只读的） |

### 3.2 图标栏态（收起后）

| 控件 | 作用 |
| --- | --- |
| **新建笔记**（顶部） | 同展开态 |
| **导航图标**（中间一列） | 11 个导航项的图标版：**选中项高亮**，鼠标移上去显示名字；点一下直接切页面，**不用先展开** |
| **展开侧边栏**（底部） | 回到展开态；与展开态的「收起」同高 |

> 这一栏只显示图标不是"丢了功能"：完整菜单项与分类树 / 标签列表在展开态里。

## 4. 笔记列表栏（中栏）

### 4.1 栏头

| 控件 | 作用 |
| --- | --- |
| **标题 + 篇数** | 当前列表的范围（全部笔记 / 某分类 / 某标签 / Inbox / 收藏 / 回收站）与条数 |
| **大纲开关** | 让「大纲」显示在**这一栏**或收起（见 §6）。没选中笔记时置灰——那时没有大纲可看 |

### 4.2 筛选与排序

| 控件 | 作用 |
| --- | --- |
| **按标题筛选** | 局部过滤当前列表（支持高亮命中片段）；清空即恢复 |
| **排序：最近修改 / 创建时间 / 标题 / 自定义顺序** | 切换排序；「自定义顺序」是拖拽排出来的顺序（写进 frontmatter 的 `order`，外部改也不丢） |
| **清除筛选**（有分类/标签筛选时出现） | 一键回到全部笔记 |

### 4.3 多选与批量

| 控件 | 作用 |
| --- | --- |
| **多选** | 进入多选模式；每行左侧出现勾选框 |
| **批量工具条** | 勾选后出现：**移动分类**、**加标签**、**复制到**（副本、原作保留）、**删除**（进回收站，可撤销） |

### 4.4 条目行

| 区域 / 控件 | 作用 |
| --- | --- |
| **层级缩进 + 折叠箭头** | 子文档按层级缩进；有子文档时箭头可折叠 / 展开 |
| **标题** | 单击打开；**标题被截断时右侧两个快捷按钮会一直显示**（不靠悬停），悬停标题看完整内容 |
| **置顶图钉 / 收藏星标** | 状态标记（置顶在任何排序下都排在该层最前） |
| **＋（新建子文档）** | 以这一篇为父，建一篇子文档（默认继承父分类） |
| **⋮（更多操作）** | 打开条目菜单，见下表 |
| **右键** | 与 ⋮ 同一套菜单 |
| **拖拽** | 拖到另一条上 = 成为它的子文档；拖到两条之间 = 同层排序；拖到侧边栏「Inbox」= 移出分类 |

条目菜单（⋮ / 右键）：

| 菜单项 | 作用 |
| --- | --- |
| 打开 | 在编辑器里打开这篇 |
| 收藏 / 取消收藏 | 加 / 去星标 |
| 置顶 / 取消置顶 | 置顶到当前层最前 |
| 创建子文档 | 同 `＋` |
| 升级为顶层文档 | 解除父子关系（子文档才有） |
| 重命名 | 改标题（可选是否同步改文件名） |
| 移动到分类 | 选目标分类 |
| 导出（Markdown / HTML / Word / PDF） | 单篇导出；PDF 走打印视图另存。**Mermaid 图在导出文件里是源码**（导出器不执行脚本）——需要图片形式请截图 |
| 创建副本 | 在当前分类里复制一份（原笔记保留） |
| 复制相对路径 / 复制标题 | 把路径或标题放进剪贴板（失败的明确提示） |
| 移到回收站 / 恢复 / 永久删除 | 依当前范围而定；回收站里只能恢复或永久删除 |

## 5. 编辑器

### 5.1 头部工具栏

| 控件 | 作用 |
| --- | --- |
| **编辑 / 分屏 / 预览** | 三种视图；选择被记住（设置里可改默认视图）。分屏比例可拖（0.3–0.7） |
| **＋ 插入内容** | 在「编辑 / 分屏 / 预览」左边；**纯预览模式下置灰**（没有光标可插）。菜单分三组：<br>**基础**：图片…（弹系统选文件框，另存到 `attachments/YYYY-MM/`）、表格、附件…（同上，插入的是链接）、待办清单<br>**程序员专区**：代码块、公式（LaTeX）、流程图、时序图、类图 / UML、思维导图（后四种都是 Mermaid，预览里直接出图）<br>**其它**：引用块、分割线、今天的日期<br>插进去的都是**普通 Markdown**；块级内容会另起一块（光标在行中时插到本行之后），不会塞进段落或加粗标记里 |
| **保存** | 立即落盘（等价 `⌘/Ctrl + S`）；自动保存默认 1 秒防抖 |
| **已同步 / 保存中 / 未保存** | 保存状态徽标**只在顶栏显示一处**；失败时显示「保存失败」+ 可点开的「详情」 |
| — | 收藏 / 移动分类 / 更多操作 **已移到顶栏**（2026-10-17，见 §2 顶栏那张表） |

**文本格式条并进工具栏同一行、始终靠右**（编辑 / 分屏模式可见）：按钮按优先级从左到右排
（**加粗**、*斜体*、~~删除线~~、行内代码、链接、无序 / 有序列表、待办、引用、标题 1-3、正文、
分割线、增减缩进）。**能放几个放几个**，窗口窄了就只显示靠前的几个，其余进「**…**」
（全都放得下时「…」不出现）；与左边「保存」之间固定留出约两个按钮宽的硬间隔，不会被挤到一起。
选中文字点一下即可加 / 去标记；没选中就插一对标记、光标停在中间直接写。

### 5.2 元信息栏

| 控件 | 作用 |
| --- | --- |
| **分类 / 文件路径** | 这篇存在哪里（路径相对工作区） |
| **更新时间 / 字数** | 元信息 |
| **被 N 篇引用 / 引用 N 篇** | 链接计数；点开看详情 |
| **来源与时效** | 打开对话框：来源类型、来源引用、可靠性（1–5）、**有效期至**——到期后首页「待复核」会提醒（留空 = 长期有效） |
| **添加标签（输入框）** | 输入后回车加标签；标签上的 × 去掉 |

### 5.3 正文区

| 操作 | 说明 |
| --- | --- |
| 写 Markdown | `#` 标题、`-` 列表、`**加粗**`、表格、代码块都支持；右侧预览实时渲染（GFM + 代码高亮） |
| **画图** | 用 ```mermaid 代码块写**流程图 / 时序图 / 类图 / 状态图 / 思维导图**等，预览里直接渲染成图（跟随深色主题）；语法写错会显示原因 + 原始代码，不会留空白。懒得记语法就用工具栏「＋」里的模板 |
| 粘贴 / 拖入图片 | 自动落到 `attachments/YYYY-MM/`，正文插入相对链接；超过 20 MB 会提示改用「导入外部文件」 |
| `[[` 触发补全 | 输入双中括号弹出标题候选（子串匹配、前缀优先）；选中补上 `]]` |
| `⌘/Ctrl + E` | 把焦点交给编辑器 |
| `⌘/Ctrl + W` | 关闭当前笔记（回到列表） |

### 5.4 关系面板（默认折叠）

| 控件 | 作用 |
| --- | --- |
| 关系（折叠标题） | 展开 / 收起面板；显示「出 N · 入 N」 |
| 添加关系 | 选类型（派生 / 取代 / 相关…）+ 目标笔记 + 说明；写出 `relations:` |
| 出边 / 入边条目 | 点目标跳转；可删除 |

### 5.5 反向链接面板

| 控件 | 作用 |
| --- | --- |
| 反向链接（标题） | 「谁引用了我」；每条显示来源笔记标题与上下文 |
| 刷新 | 重新拉取（通常自动刷新） |
| 未解析链接卡片 | 列出指向不存在笔记的链接；点「创建笔记：xxx」一键建目标并建立连接 |

### 5.6 大纲（详见 §6）

### 5.7 冲突与失败

| 控件 | 作用 |
| --- | --- |
| 冲突对话框 | 文件被外部改过：选**重新加载**（以磁盘为准）或**覆盖保存**（以编辑器为准） |
| 失败详情 | 保存 / 操作失败的完整原因、错误码（如 `NOTE_CONFLICT`）、补充信息；可一键复制 |

## 6. 大纲：两处位置与三种形态

### 6.1 大纲放在哪

| 位置 | 长什么样 | 怎么切过去 | 怎么切回来 |
| --- | --- | --- | --- |
| **与笔记列表共用一栏**（默认） | 这一栏被大纲占用，栏头是「〈〈 大纲 · 笔记标题 数量」 | 点列表栏头部的「大纲」开关 | 点栏头「〈〈」或再点一次开关 |
| **钉在正文右侧** | 正文右边独立一列（190px） | 在大纲栏头点「钉在正文右侧」；或设置 → 编辑器 → 大纲位置 | 在右侧面板点「改到笔记列表那一栏」；或改设置 |

> 「大纲位置」是**工作区级偏好**（写进设置，重开还在）；
> "这一栏此刻显示列表还是大纲"只活在本次运行里：重开应用回到列表，运行时（含切换笔记）保持你选的那个。
> 想"选中笔记就自动看结构"，去 设置 → 编辑器 打开「选中笔记后自动显示大纲"（默认关）。

### 6.2 大纲栏头

| 控件 | 作用 |
| --- | --- |
| **〈〈 返回列表** | 这一栏回到笔记列表（只在与列表共用一栏时出现） |
| **大纲 + 笔记标题 + 数量** | 「这是哪一篇的大纲」与标题条数；**标题再长栏头也只有一行**（标题自己截断，悬停看全） |
| **钉在正文右侧** | 把大纲挪到正文右边（宽屏更顺手） |
| **改到笔记列表那一栏** | 从右侧挪回中栏（右侧面板里才有） |
| **收起大纲** | 变成贴边 mini 态（右侧竖排「大纲」条；鼠标移上去临时展开；展开后点「钉住大纲」固定） |
| **大纲条目** | 按 `#` 层级缩进；点击跳到对应位置并高亮当前标题 |
| **折叠三角（▾/▸）** | 有子级的标题前有三角：点一下收起 / 展开这一节（叶子节点没有三角，标题仍然对齐） |
| **空状态文字** | 正文还没有标题时提示用 `# 标题` 开始分层 |

## 7. 首页

| 控件 | 作用 |
| --- | --- |
| **快速搜索** | 首页的搜索入口（等价 ⌘K） |
| **新建笔记** | 同侧边栏 |
| **统计卡片（Inbox 待整理 / 分类 / 标签 / 全部笔记）** | 点卡片直达对应页面 |
| **统计明细** | 正文字数、近 7 天 / 近 30 天更新、置顶数；数据只来自本地工作区 |
| **近 14 天写作活动** | 每天更新条数的柱状图 |
| **最近编辑** | 最近动过的笔记；「查看全部」去全部笔记 |
| **常用分类** | 建过的分类与计数 |
| **索引状态** | 索引是否就绪、已索引 / 总数、最近重建时间 |
| **待复核卡片** | `有效期至` 已过期或 14 天内到期的笔记；每条带「已过期 N 天 / N 天后到期」角标，点标题跳转 |

## 8. 其余页面

| 页面 | 主要控件与用法 |
| --- | --- |
| **知识图谱** `/graph` | 节点 = 笔记、边 = 双向链接；按分类着色、按度数定大小；过滤面板、1–2 跳聚焦、缩放 / 平移、拖拽固定节点、双击打开笔记 |
| **研究助手** `/research` | 课题输入 → 「生成研究计划」→「开始收集」（联网档位已开时先弹一次说明）→「验证」→「汇总」→「写入提案」（默认写 Inbox；写前给 diff；可回滚）。AI 总开关关闭时会被闸门挡住并说明原因 |
| **附件** `/attachments` | 按月份分组；每张图显示引用它的笔记；「只看未引用」筛选；删除时提示引用情况 |
| **目录管理** `/manage` | 全部文档宽表：标题 / 层级 / 分类 / 标签 / 时间 / 字数；在这里批量看与整理 |
| **分类管理** `/categories` | 新建 / 重命名（同步移动磁盘目录）/ 删除（选"移到 Inbox"或"连笔记一起删"）；显示完整相对路径 |
| **标签管理** `/tags` | 新建 / 重命名 / 删除；每个标签的笔记数 |
| **回收站** `/trash` | 只读列表；每条可**恢复**或**永久删除**；空态提示 |

| **向量检索** | 在线嵌入（复用在线模型地址与 Key）+ 一次性确认的增量构建；向量是派生数据，可一键重建、不进备份 |

| **出站代理** | "显式设置 → 环境变量 → macOS 系统代理"依次解析；**本机地址永不代理** |
| **最近行为** | 最近 5 条审计（时间 / 能力 / 结果 / 是否外发 / 错误码），可刷新 |

## 13. 把控件串成一条日常动线

1. **记**：`⌘N` 新建（或剪藏网页 / 导入 Markdown）→ 直接写，自动保存；
2. **理**：列表里拖成子文档、拖到分类上；条目 `＋` 建子文档；标签在元信息栏加；
3. **查**：`⌘K` 全局搜索（正文命中能跳回精确位置）；`⌘P` 快速切换；`/graph` 看链接关系；
4. **复核**：元信息栏「来源与时效」写来源与有效期 → 首页「待复核」会提醒；
5. **留底**：设置 → 备份与导出 → 立即备份；需要搬走时导出 Markdown。

> 数据在你自己手里：正文是普通 `.md`；`.knowledge/` 里的数据库与索引都是**派生数据**，
> 删掉也能从 Markdown 重建。
