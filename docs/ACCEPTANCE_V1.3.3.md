### B.2 真机（macOS，1280×800，窗口 `120,80`）

同一篇笔记、同一窗口位置；用 AX 坐标量「关系」标题与窗口底边：

| 指标 | V1.3.2 | V1.3.3 |
| --- | ---: | ---: |
| 底部信息区（含状态栏） | 167 px | **54 px** |
| 正文可见高度（同口径推算） | 371 px | **约 519 px** |

- 底部从 167 → 54 px（**−113 px**）；正文约 **+148 px（+40%）**；
- 展开「关系 / 反向链接」后仍受 42% 限高 + 内部滚动；
- 点摘要里的「未解析 N」会一次展开并滚到未解析列表。

> 推断口径：「正文可见高度」= 关系区标题纵坐标 − 正文滚动视口顶部纵坐标；V1.3.2 的
> 371 px 是上一轮同一方法的实测值，V1.3.3 的 519 px 用同一窗口位置与同一篇笔记推算。

## C. 全屏窗口控制

问题复现：全屏后窗口 `1512×949 @ (0,33)`，标题栏与红黄绿按钮不可见；鼠标移到顶部
**不唤出**（本机 Codex 桌面端同样如此）。

修复后实测：

1. 鼠标从正文向上扫过窗口顶部 → 浮出小胶囊（红 / 黄 / 绿 +「全屏」）；
2. 无障碍树可读到「关闭窗口」「最小化窗口」「退出全屏」三个按钮；
3. 点绿色按钮 → 窗口恢复为 **`1380×859 @ (66,33)`**，菜单栏与原生红黄绿按钮回来。

截图：`/tmp/pkos-v133-pill.png`（浮层）、`/tmp/pkos-v133-exited.png`（退出全屏后）。

> 已知限制：这是应用自绘的窗口控制，不是 macOS 原生标题栏；全屏时原生红黄绿按钮仍然隐藏。
> 关闭 / 最小化 / 退出全屏三个动作已真机验证，其他窗口动作没有加。
