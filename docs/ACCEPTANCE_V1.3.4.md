## C. 视觉修复（本版重点）

### C.1 全屏控制条：原生标题栏形态

| 项 | V1.3.3（被指出不和谐） | V1.3.4 |
| --- | --- | --- |
| 形态 | 浮动白色胶囊 | **48px 整条标题栏**（与普通窗口同高），底色 `--surface-muted`；顶部 32px 为悬停感应区 |
| 圆点 | 14px、胶囊内缩 | **12px**，间距 8px，左内缩 20px，1px 深色描边 |
| 文案 | 右侧「全屏」 | 中间 **13px 半粗** `Personal Knowledge OS` |
| 悬停图标 | 单个按钮各自出现 | 三个圆点作为一组，悬停任意一个时 × / − / 全屏图标一起出现 |

- 悬停感应改为 **document `mousemove` + `clientY ≤ 32`**，不再放透明浮层挡点击；
- 控制条挂在**应用根组件**，欢迎页（还没打开工作区）也能唤出；
- 真机对照：普通窗口标题栏与全屏标题栏同为 48px、圆点 12px / 间距 8px / 内缩 20px、标题 13px 半粗；
  全屏时鼠标在圆点上（不在窗口最上沿）即可显示，三个图标同时出现。

截图：`/tmp/pkos-v134-titlebar.png`（真机全屏、鼠标扫过顶部）。

### C.2 底部展开态：层级与空白

- 摘要条是唯一总览层：`关系 出N·入N | 反向链接 N | 未解析 N | 收起`；
- 摘要条整体左移（`pl-1`），分区标题与正文缩进到 `pl-6`：AX 实测摘要「关系」按钮 x=499、
  分区「关系」文字 x=535，父级挂在左侧、子级缩进 36px，形成总览对内容的包含关系；
- 展开后分区只保留轻量标签（关系 / 反向链接）+ 操作按钮，**不再重复角标与折叠箭头**；
- 修复了 `max-h-[42%]` 写在自适应子元素上导致的循环：V1.3.3 展开区被压到 **105px**、
  父容器留下 **114px** 空白；V1.3.4 把上限移到父容器，内容区 `flex-1 + min-h-0 + overflow-y-auto`。
- E2E 实测（1440×900）：展开内容 **218.5px**，`scrollHeight == clientHeight`（无内滚动、无空白）；
  内容超过 42% 时才出现滚动。

截图：`/tmp/pkos-v134-expanded4.png`（真机展开态，关系一条空态 + 反向链接空态 + 未解析列表）。
