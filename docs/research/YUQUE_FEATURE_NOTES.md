## 抓取方法

语雀是 SPA，直接抓 HTML 只有标题。可用两条路径拿到真实数据：

| 用途 | 请求 | 关键字段 |
| --- | --- | --- |
| 知识库（组内公开手册）列表 | `GET https://www.yuque.com/api/groups/{group_id}/books?offset=0&limit=60` | `data[].slug / name / items_count` |
| 目录树 | `GET https://www.yuque.com/yuque/{book_slug}` → HTML 内的 `window.appData = JSON.parse(decodeURIComponent("..."))` | `book.toc`（含 `title` / `slug` / `children`） |
| 文档正文 | `GET https://www.yuque.com/api/docs/{doc_slug}?book_id={book_id}&mode=markdown&plain=true` | `data.sourcecode`（Markdown） |

## 原文摘录

### 如何编排目录（知识库 `thyzgp/vlki63`）

> 如果目录中没有文档，可以选择直接新建文档，在文档下新建以后，该文档会变成**子节点**。
> 如果在顶部 “+” 新建文档，文档会排序到目录的最上面。

> 新建文档后，可直接**通过鼠标按住左键选中一个文档拖拽的方式调整文档层级**，拖动到你期望的位置后释放。
> **蓝色横线**表示拖动到的具体位置，**蓝色框**表示拖动为该节点的子级。

> 同时，如果你想将某几篇文档归类到一个分组下面，可以使用「新建分组」功能……

> 选中某个文档，点击右侧更多操作，可以对文档进行**重命名、复制、移动、导出、删除**等操作。

### 如何管理文档（`thyzgp/my8uax`）

> 进入目录管理页面以后，你可以在这里搜索、新建文档。同时也可以**批量对文档进行操作**，
> 比如复制、转移、删除、关闭分享等。

> 如果进行批量删除，可以随即进行**撤销**。

### 移出目录的文档在哪里查看（`thyzgp/yr7kdu5e1uan3k7y`）

> 知识库目录内的文档被移出目录后会被保存在知识库的**【全部文档】**中，
> 你可以点击【...】按钮，进入【目录管理】页面查看……选择【文档管理】选项，筛选文档【状态】为**不在目录中**。
> 同时，你也可以选择不在目录中的文档，重新**【添加回目录】**。

### 如何查看历史版本（`thyzgp/fs0x2z`）

> 语雀按照一定的策略自动保存历史记录……同时，编辑者也可主动保存版本，并为每一个版本命名。
> 支持：**对比任意选中的 2 个记录或者版本**、**还原**到指定的历史记录或者版本、访问指定的版本。

### 如何使用大纲（文档编辑器 `gpvawt/ug8vmn`）

> 大纲会根据文档标题自动生成，在正文中输入标题，标题内容即可在右侧大纲展示出来。

> 如果需要隐藏大纲，你可以点击「隐藏大纲」按钮，这时大纲会**收缩在右侧边缘呈现 mini 状态**；
> 如果需要将大纲调出，可以将鼠标轻滑过 mini 大纲上方……可点击「**钉住大纲**」按钮，即可在右侧固定展示。

### 如何使用模板（`thyzgp/yee00736hhtea3er`）

> 共有 2 类模板可供使用：语雀推荐模板、自定义模板。
> 自定义模板，共分为 3 类：**本知识库** / **团队** / **我的**。（另有「另存为模板」入口）

### 如何导入导出知识库（`thyzgp/import-lake-to-lark`）

> 支持的格式：Word（.docx .doc）、Excel（.xlsx .xls .csv）、Markdown（.md .markdown .mark .txt）、
> Zip 压缩包、Evernote（.html + zip）、Lakebook（语雀知识库）。
> 【注】如果需要打包导入 Markdown 文件和图片，需要**导出 Markdown 文件为 zip 格式**之后再导入。

> 支持导出 **200 篇以内**的文档，当知识库过大时，可以对知识库进行拆分。
> 单篇导出：语雀文档 → word / Markdown / PDF / JPG。

### 知识库是什么（`thyzgp/repository`）

> 在语雀「知识库」中，支持使用**文档、画板、数据表、表格**四大自研编辑器。
> 同时知识库统计里**支持查看文档明细**，你可以筛选「近 30 天」或者「近一年」……

### 如何分享文档（`thyzgp/bosazp`）

> 在分享面板中，支持两种功能：**分享给指定人**、**公开分享**（公开分享目前只支持会员使用）。
> 「分享给指定人」= 邀请对方成为协作者（站内信通知）；「公开分享」= 公开给任意游客。
>
> 文档是否公开，与知识库并无绑定关系。**公开知识库下，可以有私密文档。**

### 如何使用标签（`thyzgp/icl7ey`）

> 标签提供**跨知识库**的内容整理能力……标签仅在个人或团队内生效，无法跨团队聚合内容。
