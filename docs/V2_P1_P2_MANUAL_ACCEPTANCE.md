# V2.0.x P1 / P2 统一人工验收清单

> 自动门禁与当前状态见 [PLAN_V2_P1_P2_EXECUTION.md](./PLAN_V2_P1_P2_EXECUTION.md)。
> 本清单只列确实需要真实模型、真实远端、真实平台或人工判断的项目。
> 未执行的项目保持未勾选，不以自动化、mock 或本地桩替代。

## 1. Graph 2.0

- [ ] 准备 200 对人工标注数据（目标笔记 + 期望相关笔记集合），导出近邻 top10。
- [ ] 近邻 precision@10 达到 `>= 80%`；误连必须能通过证据解释，而不是“看起来差不多”。
- [ ] 配置真实嵌入端点并构建向量后，人工抽查共同主题、引用、标签证据是否准确。
- [ ] 抽查 20 组近重复：确认没有把相反结论或仅措辞相近的笔记建议合并。
- [ ] 抽查桥梁、孤儿与孤岛分类，确认分类边界符合实际知识库。
- [ ] 生成一次聚类摘要，检查引用、文字质量与“确认后才新建笔记”的交互。

## 2. Sync 2.0

### 2.1 真实 WebDAV

- [ ] 使用用户自己的 WebDAV endpoint，完成配置、dry-run 与双向同步。
- [ ] 两台真实设备使用同一同步口令，验证新增 / 修改 / 删除传播。
- [ ] 在服务端文件列表中确认看不到正文、标题、附件扩展名或 Markdown 明文。
- [ ] 断网修改 → 重新联网 → 查看待重试队列并成功重试。
- [ ] 两端同时修改同一段落，确认冲突不覆盖任何一端，并能选择或三方合并。
- [ ] 从历史留档恢复一次被覆盖版本与一次被删除文件。

### 2.2 真实 S3 兼容存储

- [ ] 使用用户自己的 S3 兼容服务（非官方托管云要求）完成同一组检查。
- [ ] 验证 bucket / region / endpoint / Access Key / Secret Key 错误时提示清楚且不泄露密钥。
- [ ] 验证条件上传（If-Match）在远端 manifest 已变化时拒绝覆盖。

### 2.3 安全与平台

- [ ] 抓包确认同步请求只含密文、manifest 密文、随机对象名与认证头。
- [ ] 确认应用数据目录凭据文件权限在 macOS / Linux 为 `0600`，Windows ACL 仅当前用户。
- [ ] 关闭同步后断网，验证编辑、搜索、图谱和写作仍完全可用。
- [ ] 人工检查覆盖 / 删除前历史条目的时间、来源路径与还原确认。

## 3. Scale 2.0

- [x] 10 万检索 p95 `< 200ms`、recall@5 `100%`。
- [x] 10 万 Graph 首屏 `< 3s`（2026-10-22：2866.6ms）。
- [ ] 在 Developer ID 签名 + 公证后的干净 macOS 机器上测冷启动。
- [ ] Windows 真机完成 10 万篇安装、首次启动、后台扫描与内存观察。
- [ ] Linux Ubuntu 22.04 / 24.04 真机完成同样检查。
- [ ] 人工检查 10 万命中高频词的滚动、翻页与虚拟列表，不出现白块或跳动。
- [x] 4 个稳定 FTS 分片的迁移、映射一致性、跨分片检索与分页已由自动测试覆盖。

## 4. Writing 2.0

- [ ] 配置真实的已授权在线模型与可选本地模型，分别测试五类写作模式。
- [ ] 人工评估结构、事实一致性、语气、重复与段落连贯性。
- [ ] 逐段核对引用：句意确实由引用来源支撑，没有“引用了但内容无关”。
- [ ] 测试来源笔记被外部修改后，旧草稿必须拒绝写入。
- [ ] 测试目标笔记被外部修改后，旧草稿必须返回 `NOTE_CONFLICT`。
- [ ] 在 macOS / Windows 真机检查长文 diff、逐段选择、取消、确认和历史回滚。
- [ ] 验证未确认在线外发时，网络抓包与审计均证明零请求。
