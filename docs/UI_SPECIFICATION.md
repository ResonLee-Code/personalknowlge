# 界面规范

对应设计文档第 15 / 16 / 17 章。

## 1. 布局

三栏工作台，符合设计文档 16.1 的宽度建议：

```text
+---------------------------------------------------------------+
| 侧边栏开关 知识库名称   全局搜索(⌘K)      保存状态 主题 设置    |  TopBar 48px
+--------------+----------------------+-------------------------+
| 工作区切换    | 列表标题 + 筛选       | 标题输入                |
| 新建笔记      | 排序：最近/创建/标题  | 编辑 / 分屏 / 预览       |
| 导航（10 项） | 笔记卡片（高亮摘要）  | Markdown 编辑器          |
| 分类树        | 空状态 + 新建按钮     | 预览（GFM + 代码高亮）   |
| 标签          |                      | 标签编辑 / 元信息        |
+--------------+----------------------+-------------------------+
| 索引状态 · 统计 · 当前列表数量 · 错误提示 · 运行模式            |  StatusBar 28px
+---------------------------------------------------------------+
```

- 左栏默认 248px（180–420），支持拖拽分栏把手调整，可折叠为 44px 图标栏；
- 中栏默认 320px（240–520，底部滑块调整）；
- 右栏占剩余空间。

## 2. 路由

采用 HashRouter（桌面外壳以静态资源方式加载单页应用）：

| 路由 | 页面 | 优先级 |
| --- | --- | --- |
| `/` | 首页（快速搜索、统计、最近编辑、常用分类、索引状态） | P0 |
| `/notes`, `/notes/:id` | 全部笔记 / 笔记编辑 | P0 |
| `/inbox`, `/inbox/:id` | Inbox | P0 |
| `/favorites`, `/favorites/:id` | 收藏 | P1 |
| `/graph` | 知识图谱（节点 + 连接 + 过滤 + 聚焦 + 社区着色） | P1 |
| `/attachments` | 附件管理（按月份分组、引用提示、删除） | P1 |
| `/trash`, `/trash/:id` | 回收站（只读 + 恢复 / 永久删除） | P0 |
| `/missing`, `/missing/:id` | 文件缺失（外部删除或移动） | P1 |
| `/search` | 搜索页面（关键词 + 筛选 + 分页） | P0 |
| `/categories` | 分类管理 | P0 |
| `/tags` | 标签管理 | P1 |
| `/settings` | 设置 | P1 |
| `/about` | 关于与版本信息 | P2 |
| `/notes?categoryId=…`、`/notes?tagId=…` | 按分类 / 标签筛选列表 | P0 |

未打开工作区时显示欢迎页：创建 / 打开知识库、最近打开列表、产品定位说明。

## 3. 组件结构

```text
AppShell
├── TopBar                → 全局搜索入口、保存状态、主题切换、设置
├── Sidebar               → WorkspaceSwitcher + NavigationMenu + CategoryTree + TagList + 重新扫描
├── main (Outlet)
│   └── NotesSection      → NoteListPanel + NoteEditorPage | 空状态
│       ├── NoteListPanel → 标题与数量、标题筛选、排序、NoteListItem、空状态、宽度滑块
│       └── NoteEditorPage→ 模式切换、保存、收藏、移动分类、更多菜单
│           ├── MarkdownEditor (CodeMirror 6)
│           ├── MarkdownPreview (react-markdown + remark-gfm + rehype-highlight)
│           ├── TagEditor
│           ├── BacklinkPanel      → 反向链接 + 本篇未解析链接
│           ├── OutlinePanel       → `#` 标题大纲，点击跳转
│           └── ConflictDialog / MoveNoteDialog / RenameFileDialog
└── StatusBar             → 索引状态、统计、运行模式、错误摘要
GlobalSearchDialog（⌘K 面板）、NewNoteDialog（⌘N）
```

新建笔记对话框有两个页签：**手动创建**（标题 / 分类 / 标签 / 初始内容）与
**导入外部文件**（多选 `.md`/`.markdown`/`.txt` 或选择文件夹递归导入、查看成功与跳过清单）。
当 `.knowledge/templates/` 下存在模板时，手动创建页签会多出一个「模板」下拉，
选中即把渲染后的内容填入初始内容（V1.1 M2-2）。

中栏列表宽度通过列表与编辑器之间的拖拽把手调整（与左侧边栏一致），
列表底部仅在按分类/标签筛选时显示「清除筛选，查看全部笔记」。

### 分栏与导出（V1.0.1 增补）

- 三处可拖拽分栏：侧边栏（180–420px）、笔记列表（240–560px）、分屏模式下的编辑/预览比例（0.3–0.7）；
  拖动时按帧合并更新，结束才写入设置；双击复位默认值，方向键可微调 16px；
- 分屏比例通过回调 ref + `ResizeObserver` 获取容器宽度后再换算，首次进入笔记即可自然拖动；
  像素类数值取整、比例保留三位小数（避免 Retina 屏上的小数坐标导致设置写入失败）；
- 宽度、比例、主题、字号随工作区保存，切回同一知识库时自动恢复；
- 视图模式（编辑 / 分屏 / 预览）在编辑器顶部切换后**立即持久化**，
  打开或切换笔记时保持一致，不会退回旧模式；
- 编辑页「更多操作 → 导出」提供四种格式：Markdown（原样，含 frontmatter）、
  网页 HTML（自包含，可打印为 PDF）、Word (.docx)、PDF（打印视图另存）；
- 首页、设置、分类、标签等页面内容占满可用宽度（宽屏下采用两列布局），不再留出大片空白。

### 双向链接（V1.1 M1-3 增补）

- 编辑器底部固定「反向链接」面板，可折叠：标题栏显示「被 N 篇引用」，有未解析链接时显示琥珀色计数；
- 反链条目展示来源标题 + 上下文摘要 + 相对时间，点击跳转到来源笔记；
- 面板下半部分列出本篇未解析的 `[[…]]`，点「创建」按目标标题新建笔记，
  后端自动重绑并刷新面板；
- 编辑器元信息栏显示 `被 N 篇引用 / 引用 M 篇`，未解析时追加 `N 处未解析`（琥珀色）；
- 首页右下「未解析链接」卡片汇总全库未解析链接（默认 5 条，其余给出剩余数量提示），
  支持一键创建与跳转来源；
- 链接数据属于可重建派生数据：读取失败时面板降级为空列表，不阻塞编辑；
  保存成功后计数与面板自动刷新。

### 编辑体验（V1.1 M2-1 增补）

- **图片粘贴/拖拽**：编辑器内粘贴或拖入图片即写入 `attachments/YYYY-MM/`，
  正文插入相对当前笔记目录的链接；预览会内联显示工作区内的相对图片；
  超过 20 MB 的附件提示改用「导入外部文件」，读取失败时保留原始链接（不阻塞编辑）；
- **大纲**：工具栏「大纲」按钮（编辑 / 分屏模式）打开右侧大纲栏，按层级缩进列出 `#` 标题，
  点击跳转并高亮；没有标题时给出 `.md` 书写引导；
- **快速切换**：`⌘/Ctrl + P` 打开标题快速切换面板（模糊匹配、↑↓ 选择、回车打开、Esc 关闭）；
- 大纲栏宽度固定 190px，不参与分屏比例换算，因此拖拽分屏把手的手感不受影响。

### 双向链接体验（V1.1 M2-2 增补）

- **`[[` 自动补全**：输入 `[[` 弹出标题候选（子串匹配、前缀优先、最多 20 条），
  选中补上 `]]`；`Esc` 关闭，失焦自动收起；
- **预览 chip**：`[[标题]]` 渲染为 chip —
  - 已解析：品牌色实心 chip，点击跳转目标笔记；
  - 未解析：琥珀色虚线 chip（`+` 图标），点击创建目标笔记并自动建立连接后跳转；
- chip 只在预览渲染层生效，Markdown 源文件保持 `[[…]]` 原文；
  代码块与行内代码中的 `[[…]]` 不参与（与解析规则一致）。

### 本地模板（V1.1 M2-2 增补）

- 模板目录：`.knowledge/templates/*.md`（新建工作区时写入一个「会议记录」示例模板）；
- 新建笔记对话框：存在模板时显示「模板」下拉（默认「不使用模板」），
  选择后渲染结果直接填入「初始内容」，仍可手动修改；已选模板且正文未被手改时，
  修改标题会跟随重新渲染 `{{title}}`；
- 占位符：`{{title}}` `{{date}}` `{{time}}` `{{datetime}}` `{{weekday}}`
  （另接受 `{{标题}}` `{{日期}}` `{{时间}}`），未知占位符原样保留；
- 模板读取失败（例如浏览器预览模式）时静默忽略，不影响手动创建。

### 知识图谱（V1.1 M3 增补）

- 入口：侧边栏「知识图谱」（`/graph`）；右上角显示「N 个节点 · M 条连接 · 耗时 ms」；
- 画布交互：滚轮缩放（以指针为中心，0.15×–4×）、拖拽空白平移、拖拽节点固定位置、
  单击选中并高亮其连接、双击打开笔记、`F` 键适应窗口；
- 布局：收敛前每 15 帧自动取景，收敛后停止渲染帧（静态画面不占 CPU），
  数据或筛选变化时重建布局；
- 筛选：分类（含子分类）、标签、孤立节点开关、聚焦当前笔记（1 跳 / 2 跳）；
- 右栏：图例（分类配色 + 未分类灰色，最多 6 项）、选中笔记详情（邻居数、标签、聚焦/打开）、
  操作说明；节点大小 = 可见子图内的邻居数；
- 截断提示：超过 2000 节点或 5000 条连接时按连接度优先保留，并在顶部用琥珀色提示建议先筛选。

### 导入工具（V1.1.2 增补）

- 导入页签新增「导入格式」下拉：自动识别（默认）/ 通用 Markdown / Obsidian 库 / Notion 导出；
- 自动识别：目录内有 `.obsidian/` → Obsidian；出现 `名称 <32 位十六进制>.md` → Notion；
- 两种模式下图片/PDF 等附件会一并复制到 `attachments/YYYY-MM/`，正文引用自动改写；
- 成功提示显示「已导入 N 篇笔记，附 M 个附件（Obsidian/Notion）」。

### 搜索历史与收藏条件（V1.1.2 增补）

- 搜索框下方显示「最近搜索」（最多 6 个 chip，点击恢复条件）与「收藏的搜索」（点击恢复、✕ 删除）；
- 有有效条件时显示「保存当前搜索条件」，弹窗只需填名字（默认取关键词）；
- 历史与收藏按工作区保存在本地，不进入知识库文件，也不随备份带走。

### 拖拽移动分类（V1.1.2 增补）

- 笔记行可拖拽：放到侧边栏分类 → 移动到该分类；放到 Inbox → 移出分类；
- 放置目标高亮（`ring`），松开即执行并提示结果；多选状态下拖动一行会带走整批；
- 自定义 MIME `application/x-pkos-note` 承载 id 数组，非笔记拖拽一律忽略。

### 批量操作（V1.1.2 增补）

- 笔记列表工具条新增「多选」：进入后每行左侧出现勾选框，顶部工具条显示
  「已选 N / 全选 / 清除 / 移动 / 标签 / 删除 / 退出」；
- `Cmd/Ctrl + 点击` 任意行即可切换选择并自动进入多选；多选模式下单击行 = 勾选（不打开笔记）；
- 批量删除为移入回收站（二次确认），批量移动与打标签使用独立对话框。

### 附件管理（V1.1.2 增补）

- 侧边栏「附件」进入 `/attachments`：头部显示「文件数 · 总占用 · 被引用 / 未引用」；
- 列表按 `YYYY-MM` 目录分组，每行显示文件名、体积、修改时间、引用它的笔记（可点击跳转）或「未引用」标记；
- 删除按钮带二次确认；若仍被笔记引用，确认框内列出引用笔记并提示「引用会失效」；
- 导入对话框新增「保留目录结构」勾选：在目标分类下重建子目录并保留原文件名。

### 类型化关系与回收站（V1.1.2 增补）

- 编辑器底部「关系」面板（**默认折叠**，避免挤占编辑区）：出边展示「类型徽标 + 目标笔记 + 说明」
  并可删除；入边只读列出「谁与本篇有关系」；「添加关系」对话框支持按标题搜索目标笔记；
- 元信息栏角标：已被「X」取代 / 已取代「Y」/ N 处冲突（琥珀色与红色区分严重程度）；
- 编辑区最小高度 180px，底部面板（关系 / 反向链接）都不会把编辑器压到不可用；
- 回收站列表按「今天 / 昨天 / 近 7 天 / 更早」分组，底部提供「清空回收站（N）」（二次确认后永久删除）。

### 来源与时效（V1.1.2 N1 增补）

- 编辑器元信息栏显示「来源类型 + 可靠性星标」，逾期显示琥珀色「可能已过期」、30 天内显示「即将到期」；
- 「更多操作 → 来源与时效」或点击元信息栏的来源标签打开编辑对话框（来源类型 / 引用 / 可靠性 1–5 / 有效期至）；
- 字段写回 Markdown frontmatter，可用任何编辑器修改，应用扫描后自动同步。

### 文档目录树与条目操作（V1.2.1 增补，对标语雀）

- **目录树**：列表按 `parentId` 组装「父文档 → 子文档」两级（多层也支持）展示；
  父文档行显示展开 / 折叠箭头（默认展开，折叠状态仅当前会话记忆），
  子文档按层级缩进（每级 12px）；父子关系独立于分类目录，不改变文件位置；
- **子文档创建**：条目菜单 →「创建子文档」→ 填写标题即创建并打开，
  子文档默认**继承父文档分类**，父文档标题在对话框中回显；
- **升级为顶层文档**：子文档条目菜单提供该入口（等价于清空 `parent`）；
- **长标题**：标题截断时悬停显示完整标题（tooltip 走传送门，不被列表滚动容器裁切）；
- **条目操作菜单**：`⋮` 按钮与**右键菜单**双入口，内容一致——
  打开 / 收藏 / 置顶 / 创建子文档 / 升级为顶层文档 / 重命名 / 移动分类 /
  导出（MD·HTML·Word·PDF）/ 创建副本 / 移到回收站（回收站内为恢复 / 永久删除）；
- **正文右侧常驻大纲（V1.2.1 界面调整）**：大纲固定在工作区最右侧（`[分类树][列表][编辑|预览][大纲]`），
  **默认展开**，三种编辑模式下都在；显示当前笔记的标题层级与数量，并高亮光标所在标题；
  点标题跳到对应位置——编辑器可用时跳编辑器，纯预览模式按标题序号滚动预览区；
  面板内「收起大纲」→ 贴边 mini 态（悬停临时展开）、「钉住大纲」→ 恢复常驻；
  工具栏的大纲按钮在常驻 / mini 态下点击即隐藏。

### 列表条目形态（V1.2.1 界面调整，对标语雀）

- 条目为**单行**：`缩进 + 折叠箭头 + 标题 +（置顶图钉 / 收藏星标）`，右侧 hover 出现
  「+ 新建子文档」与「⋮」；标题超长时截断，悬停显示完整标题；
- **不再显示**相对时间、分类路径、标签与子文档计数——这些在预览页元信息栏与
  「目录管理」页的宽表里都能看到；只有关键词筛选时在标题下方显示命中摘要（高亮匹配片段）；
- 选中态用品牌色描边 + 浅色底；多选模式下左侧出现勾选框；
- 拖拽落点提示不变（中间蓝色框 = 成为子文档，上下蓝色横线 = 同层插入）。

### 拖拽建立层级与排序（V1.2.1 增补，对标语雀）

- **落点语义**（与语雀一致）：拖到条目的**上 30% / 下 30%** → 蓝色横线，插到该条目前 / 后；
  拖到条目**中间 40%** → 蓝色框，成为它的子文档。落点判定是纯函数
  `noteDragDrop.noteDropPosition`，30/70 分带；
- **非法落点**（拖到自己或自己的子树上）不显示提示，落下时提示「不能把笔记移动到它自己的子文档下」；
- **多选拖拽**：按当前勾选批量处理，保持相对顺序；
- 拖成子文档后会自动展开该父文档，并提示「已移动到「X」下」；
- **同层插入**需要「自定义顺序」才有意义：在其它排序下拖拽插入会自动切换到该顺序
  （toast 提示「已切换为「自定义顺序」，可继续拖拽调整」）；工具条排序选项新增
  「自定义顺序」（`manual`）；
- 排序写入 frontmatter 的 `order:`（数字）**不会**修改 `updated_at`，
  因此「最近修改」列表的顺序不受影响；
- 与「拖到分类 / Inbox」的关系：拖到列表内条目 = 调层级 / 排序；
  拖到侧边栏分类仍是移动分类（两套交互互不干扰，笔记拖拽使用同一份 drag 数据）。
- **排序记忆**：排序选择写进工作区设置（`listSort`），重开应用 / 切换知识库后自动恢复；
- **「不在目录中」筛选**（工具条开关，对标语雀「移出目录 → 全部文档」）：
  打开后只显示没有被任何父文档收纳的顶层文档；空状态会说明「当前所有笔记都被某个父文档收纳」；
- **删除可撤销**：单篇与批量删除的 toast 都带「撤销」按钮，点击从回收站恢复
  （批量只恢复成功删除的笔记，失败项不会被动到）。
- **置顶**：条目菜单「置顶 / 取消置顶」（对标语雀「置顶文档」）；置顶后条目元信息
  显示「已置顶」，且在**任何排序方式**下都排在该层最前；
  子文档置顶只在同一层内生效（仍跟在父文档下，不会跳到顶层）。
- **目录整树折叠**：工具条「折叠全部 / 展开全部」按钮（仅当存在子文档时出现），
  一键收起或展开整棵树；
- **批量复制到分类**：多选工具条「复制到」→ 选择目标分类 → 副本落到该分类，**原作保留**；
- **单篇「复制到分类…」**（条目菜单）：与批量同语义（副本带「副本」后缀、原作保留），
  分类计数与列表随之刷新；
- **复制相对路径 / 复制标题**：条目菜单两项（对标语雀「复制链接」），
  复制失败（无剪贴板权限）时给出明确提示。

### 从网页剪藏（V1.2.1 C1 增补）

- 入口：新建笔记对话框第三个页签「从网页剪藏」；
- 交互：填地址 →「抓取」（等待中按钮转圈）→ 成功后显示**可编辑标题**、站点、字数、抓取时间，
  以及正文前 12 行预览；再次抓取会覆盖预览；失败时给出明确错误并保持「剪藏为新笔记」不可用；
- 剪藏后：创建笔记 → 写入来源元数据（`source_type: web`）→ 直接打开该笔记；
  正文抬头固定写「> 来源：<最终地址> / 抓取于 <时间>」，便于日后核对时效；

### 设置 → AI（V1.2.1 D1 增补）

- 区块标题「AI（第二代预留）」，默认展示最保守口径：总开关关闭、联网「仅本地」、抓取正文关闭；
- 切到「允许联网检索」时先弹**说明对话框**（会上传检索片段与问题、不上传整篇知识库、
  受白/黑名单约束、可随时切回），确认后才提交 `network=allowNetwork + confirmNetwork=true`；
  选「暂不启用」则保持「仅本地」且不提交；
- 域名白名单（留空 = 不预置）/ 黑名单（强制丢弃）各一个多行输入框，失焦即保存；
- **检索源地址**（D3）：单行输入，失焦即保存；提示写明「应用不预置任何第三方检索服务」、
  必须含 `{query}`、支持 SearxNG `{ "results": [ … ] }` 形状；不合法或缺少 `{query}` 会被清空；
- 研究预算三个数字输入（子问题上限 10 / 抓取页上限 50 / 时长上限 1800s，后端会夹取）；
- **本地模型（D5）**：地址（`http://127.0.0.1:11434`）+ 模型名两行输入（失焦即保存），
  加两个开关「用本地模型写报告」「用本地模型打分」，**默认都关**；提示语写明：
  只连本机地址、远程模型需单独授权、两开关都关时一个请求都不发、
  浏览器预览模式不会真的调用本地模型、打分未校准（级别折算仍占一半，不是 Jev）；
- 「最近行为」列出最近 5 条审计（时间 / 能力 / 结果 / 是否外发 / 错误码），可手动刷新。

### 分类管理页的目录展示（V1.2.1 修正）

  这样嵌套分类不会被误读成「就在根目录」；未创建目录的分类沿用父目录，都没有则显示「（无目录）」；

## 4. 编辑器行为（设计文档 16.5）

| 状态 | 表现 |
| --- | --- |
| 未保存 | 顶栏显示「未保存」 |
| 保存中 | 显示旋转图标「保存中」，串行化避免并发写入 |
| 已保存 | 显示「已保存」，元信息栏显示索引时间 |
| 保存失败 | 显示「保存失败」，悬停展示后端错误；正文仍在编辑器中 |
| 外部冲突 | 弹出冲突对话框：重新加载磁盘内容 / 用当前内容覆盖 |
| 回收站笔记 | 编辑器只读，保存按钮禁用，提供恢复与永久删除 |

自动保存默认开启（1000ms 防抖），可在设置中关闭或调整 200–10000ms。

## 5. 反馈与空状态（设计文档 17.2 / 17.3）

- toast 覆盖：保存、删除、移动、恢复、备份、索引重建、扫描结果、外部修改提示；
- 每个列表都提供空状态与下一步操作按钮：笔记列表、搜索结果、分类、标签、回收站、缺失文件；
- 破坏性操作（删除笔记、删除分类、永久删除）均需二次确认。

## 7. 主题与可访问性

- 浅色 / 深色两套 CSS 变量（`--surface`、`--ink`、`--brand` 等），切换写入 `html.dark`；
- 焦点可见（`focus-visible:ring`）；
- 交互元素具备 `title` 或 `aria-label`；
- 分栏把手使用 `role="separator"` 支持指针拖拽。
