# 界面规范

对应设计文档第 15 / 16 / 17 章。

## 1. 布局

三栏工作台，符合设计文档 16.1 的宽度建议：

```text
+---------------------------------------------------------------+
| 知识库名称 搜索(⌘K) 已同步  收藏 移动分类 ⋯ 主题 设置          |  TopBar 48px
+--------------+----------------------+-------------------------+
| 工作区切换    | 列表标题 + 筛选       | ＋ 编辑/分屏/预览 保存    |
| 新建笔记      | 排序：最近/创建/标题  | （同一行右侧：格式条+…）  |
| 导航（11 项） | 笔记卡片（高亮摘要）  | Markdown 编辑器          |
| 分类树        | 空状态 + 新建按钮     | 预览（GFM + 代码高亮）   |
| 标签          |                      | 标签编辑 / 元信息        |
+--------------+----------------------+-------------------------+
| 索引状态 · 统计 · 当前列表数量 · 错误提示 · 运行模式            |  StatusBar 28px
+---------------------------------------------------------------+
```

- 左栏默认 248px（180–420），支持拖拽分栏把手调整，可折叠为 44px 图标栏；
- **侧边栏开关只有一个**（V1.3.0 第二轮界面调整）：放在侧边栏**底部那一行**（与「重新扫描」同排），
  收起后的 44px 图标栏里「展开」也在**同一高度**——两个状态下开关不跳位置；
  顶栏原来那个「切换侧边栏」已删除（同一个动作不该有两个按钮）；
- **收起态是图标栏，不是空栏**（同轮调整）：44px 宽里按顺序放「新建笔记」+ **全部导航项图标**
  （选中项品牌色底、悬停出名字），底部才是「展开侧边栏」。
  以前收起后只剩「新建笔记」，想切页面得先展开——**收起不等于失去导航**；
- **「设置」入口只有右上角一个**：侧边栏导航里的重复项已删除；
- **分类 / 标签区块可折叠**（点区块标题）：分类多了不把侧边栏顶长；折叠状态只活在内存里
  （与侧边栏折叠同口径，不写设置）；
- 中栏默认 320px（240–520，底部滑块调整）；
- 中栏**头部**：`标题 + 篇数`（篇数紧贴标题）在左、「大纲」开关在最右（V1.3.0 第二轮界面调整：
  开关从编辑器工具栏挪到这里——列表栏一直都在，而工具栏只在打开笔记时才有）；
  没选中笔记时开关置灰（那会儿没有大纲可看，点上去不该什么都不发生）；
- 右栏占剩余空间。
- **设置页右栏**（2026-10-17）：**单列铺满**——之前那套多列瀑布流在"一次只显示一节"之后成了坑：
  窗口越宽越会分列，而单节只有一张卡片，卡片被塞进半列、右边空一片（窗口越宽内容反而越窄）。
- **顶栏右侧**（2026-10-17）：打开着笔记时依次是 **收藏 / 移动分类 / 更多操作**（笔记级动作，
  从编辑器工具栏搬上来）、主题、设置；「已同步」不再贴在最右，而是**紧挨搜索栏**，
  搜索栏与它整体偏左——以前搜索框居中、保存状态贴右，中间空一大段（附图 1 的要求）。
  顶栏只发**动作请求**（`uiStore.requestNoteAction`），对话框仍由编辑器消费并渲染。

大纲**默认不另占一列**（V1.3.0 布局调整）：它和笔记列表**共用中栏**，在同一栏里按需切换
（平时是列表，点中栏头部的大纲开关则这一栏换成大纲，栏头「〈〈 返回列表」切回）；必要时可钉回正文右侧，
那时布局与 V1.2.1 相同：

```text
默认（三列）       [分类树][列表 ⇄ 大纲][编辑|预览]
钉在右侧（四列）    [分类树][列表][编辑|预览][大纲]
```

## 2. 路由

采用 HashRouter（桌面外壳以静态资源方式加载单页应用）：

| 路由 | 页面 | 优先级 |
| --- | --- | --- |
| `/` | 首页（快速搜索、统计、最近编辑、常用分类、索引状态） | P0 |
| `/notes`, `/notes/:id` | 全部笔记 / 笔记编辑 | P0 |
| `/inbox`, `/inbox/:id` | Inbox | P0 |
| `/favorites`, `/favorites/:id` | 收藏 | P1 |
| `/graph` | 知识图谱（节点 + 连接 + 过滤 + 聚焦 + 社区着色） | P1 |
| `/attachments` | 附件管理（按月份分组、引用提示、删除） | P1 |
| `/trash`, `/trash/:id` | 回收站（只读 + 恢复 / 永久删除） | P0 |
| `/missing`, `/missing/:id` | 文件缺失（外部删除或移动） | P1 |
| `/search` | 搜索页面（关键词 + 筛选 + 分页） | P0 |
| `/categories` | 分类管理 | P0 |
| `/tags` | 标签管理 | P1 |
| `/settings` | 设置 | P1 |
| `/about` | 关于与版本信息 | P2 |
| `/notes?categoryId=…`、`/notes?tagId=…` | 按分类 / 标签筛选列表 | P0 |

未打开工作区时显示欢迎页：创建 / 打开知识库、最近打开列表、产品定位说明。

## 3. 组件结构

```text
AppShell
├── TopBar                → 全局搜索入口、保存状态、主题切换、设置
├── Sidebar               → 展开态：WorkspaceSwitcher + NavigationMenu + CategoryTree（可折叠）
│                           + TagList（可折叠）+ 重新扫描 + 收起侧边栏
│                           收起态：44px 图标栏（新建笔记 + 全部导航项图标 + 展开侧边栏）
│                           两态共用 navItems.ts 的导航项定义（免得两处对不上）
├── main (Outlet)
│   └── NotesSection      → (NoteListPanel | OutlinePane) + NoteEditorPage | 空状态
│       ├── NoteListPanel → 标题 + 篇数、OutlineToggleButton（大纲开关）、标题筛选、排序、
│       │                   NoteListItem、空状态、宽度滑块
│       ├── OutlinePane   → 与列表同栏的大纲（V1.3.0；订阅 outlineStore，见「大纲的两处位置」）
│       └── NoteEditorPage→ 模式切换、保存、收藏、移动分类、更多菜单
│           ├── MarkdownEditor (CodeMirror 6)
│           ├── MarkdownPreview (react-markdown + remark-gfm + rehype-highlight)
│           ├── TagEditor
│           ├── BacklinkPanel      → 反向链接 + 本篇未解析链接
│           ├── OutlinePanel       → `#` 标题大纲，点击跳转（列表栏态 / 正文右侧态共用）
│           └── ConflictDialog / MoveNoteDialog / RenameFileDialog
└── StatusBar             → 索引状态、统计、运行模式、错误摘要
GlobalSearchDialog（⌘K 面板）、NewNoteDialog（⌘N）
```

新建笔记对话框有两个页签：**手动创建**（标题 / 分类 / 标签 / 初始内容）与
**导入外部文件**（多选 `.md`/`.markdown`/`.txt` 或选择文件夹递归导入、查看成功与跳过清单）。
当 `.knowledge/templates/` 下存在模板时，手动创建页签会多出一个「模板」下拉，
选中即把渲染后的内容填入初始内容（V1.1 M2-2）。

中栏列表宽度通过列表与编辑器之间的拖拽把手调整（与左侧边栏一致），
列表底部仅在按分类/标签筛选时显示「清除筛选，查看全部笔记」。

### 分栏与导出（V1.0.1 增补）

- 三处可拖拽分栏：侧边栏（180–420px）、笔记列表（240–560px）、分屏模式下的编辑/预览比例（0.3–0.7）；
  拖动时按帧合并更新，结束才写入设置；双击复位默认值，方向键可微调 16px；
- 分屏比例通过回调 ref + `ResizeObserver` 获取容器宽度后再换算，首次进入笔记即可自然拖动；
  像素类数值取整、比例保留三位小数（避免 Retina 屏上的小数坐标导致设置写入失败）；
- 宽度、比例、主题、字号随工作区保存，切回同一知识库时自动恢复；
- 视图模式（编辑 / 分屏 / 预览）在编辑器顶部切换后**立即持久化**，
  打开或切换笔记时保持一致，不会退回旧模式；
- 编辑页「更多操作 → 导出」提供四种格式：Markdown（原样，含 frontmatter）、
  网页 HTML（自包含：内联样式 + 工作区图片内联为 data URL，可打印为 PDF）、
  Word (.docx，图片以「[图片]」占位)、PDF（打印视图另存，图片同样内联）；
- 首页、设置、分类、标签等页面内容占满可用宽度（宽屏下采用两列布局），不再留出大片空白。

### 双向链接（V1.1 M1-3 增补）

- 编辑器底部固定「反向链接」面板，可折叠：标题栏显示「被 N 篇引用」，有未解析链接时显示琥珀色计数；
- 反链条目展示来源标题 + 上下文摘要 + 相对时间，点击跳转到来源笔记；
- 面板下半部分列出本篇未解析的 `[[…]]`，点「创建」按目标标题新建笔记，
  后端自动重绑并刷新面板；
- 编辑器元信息栏显示 `被 N 篇引用 / 引用 M 篇`，未解析时追加 `N 处未解析`（琥珀色）；
- 首页右下「未解析链接」卡片汇总全库未解析链接（默认 5 条，其余给出剩余数量提示），
  支持一键创建与跳转来源；
- 链接数据属于可重建派生数据：读取失败时面板降级为空列表，不阻塞编辑；
  保存成功后计数与面板自动刷新。

### 编辑体验（V1.1 M2-1 增补）

**编辑器工具栏（2026-10-16 增补）**：

| 位置 | 控件 | 行为 |
| --- | --- | --- |
| 最左 | **插入菜单（＋）** | 编辑 / 分屏模式可用（纯预览置灰）。菜单分「基础 / 程序员专区 / 其它」：图片、表格、附件、待办、代码块、公式（LaTeX）、流程图、时序图、类图 / UML、思维导图、引用、分割线、今天的日期。插的都是标准 Markdown；**图片与附件弹系统文件选择框**（落 `attachments/YYYY-MM/`，正文插相对路径/链接）。块级内容**另起一块**（光标不在空行时插到本行之后），不会塞进段落或 `**加粗**` 标记中间。<br>**菜单清单口径**（2026-10-18 审计）：语雀面板里的画板 / 数据表 / 画册 / 看板 / 状态 / AI 助手 / 折叠块是**私有块**，没有 Markdown 对应物，**有意不做**（否则内容离开本应用就失效）；其余能在 Markdown 里表达的都已覆盖 |
| 同一行右侧 | **文本格式条（实测宽度版）** | 2026-10-17 起并入工具栏同一行（以前独占第二行、把编辑区往下推）。按钮**按优先级从左到右**排列、**始终靠右**；宽度由 `ResizeObserver` 实测，**能放几个放几个**，放不下的才进「…」（全都放得下时「…」不出现）。与「保存」之间留**硬间隔**（≈132px，两个保存按钮宽），格式条不得越过。实测：1600 宽 16 个全铺开 / 1440 宽 13 个+「…」/ 1100 宽 1 个+「…」 |
| （旧）第二行 | ~~文本格式条~~ | 标题（正文 / H1 / H2 / H3）、无序 / 有序列表、待办、引用、加粗、斜体、删除线、行内代码、链接、分割线、增减缩进。选中文字点一下即加 / 去标记；没选中时插一对标记、光标停在中间。命令是纯函数（`lib/markdownCommands.ts`），最小改动 dispatch 进 CodeMirror |
| 右端 | **收藏** | 收藏后**橙色实心**星标，再点回到未收藏（描边星号） |
| — | **保存状态** | **只在顶栏显示一次**（编辑器工具栏不再重复「已同步」） |

**```mermaid 代码块会渲染成图**（2026-10-16）：流程图 / 时序图 / 类图 / 状态图 / 思维导图等；
跟随深浅色主题；语法错误时显示原因 + 原始代码（不留空白）。mermaid 按需加载。

- **图片粘贴/拖拽**：编辑器内粘贴或拖入图片即写入 `attachments/YYYY-MM/`，
  正文插入相对当前笔记目录的链接；预览会内联显示工作区内的相对图片；
  超过 20 MB 的附件提示改用「导入外部文件」，读取失败时保留原始链接（不阻塞编辑）；
- **大纲**：中栏头部的「大纲」开关打开大纲，按层级缩进列出 `#` 标题，
  点击跳转并高亮；没有标题时给出 `.md` 书写引导；
  它默认显示在**笔记列表那一栏**（见 §1「大纲默认不另占一列」与文末「大纲的两处位置与设置项」）；
- **快速切换**：`⌘/Ctrl + P` 打开标题快速切换面板（模糊匹配、↑↓ 选择、回车打开、Esc 关闭）；
- 大纲**钉在正文右侧**时宽度固定 190px，不参与分屏比例换算，因此拖拽分屏把手的手感不受影响；
  与笔记列表共用一栏时则沿用列表宽度（那条拖拽把手继续生效）。

### 双向链接体验（V1.1 M2-2 增补）

- **`[[` 自动补全**：输入 `[[` 弹出标题候选（子串匹配、前缀优先、最多 20 条），
  选中补上 `]]`；`Esc` 关闭，失焦自动收起；
- **预览 chip**：`[[标题]]` 渲染为 chip —
  - 已解析：品牌色实心 chip，点击跳转目标笔记；
  - 未解析：琥珀色虚线 chip（`+` 图标），点击创建目标笔记并自动建立连接后跳转；
- chip 只在预览渲染层生效，Markdown 源文件保持 `[[…]]` 原文；
  代码块与行内代码中的 `[[…]]` 不参与（与解析规则一致）。

### 本地模板（V1.1 M2-2 增补）

- 模板目录：`.knowledge/templates/*.md`（新建工作区时写入一个「会议记录」示例模板）；
- 新建笔记对话框：存在模板时显示「模板」下拉（默认「不使用模板」），
  选择后渲染结果直接填入「初始内容」，仍可手动修改；已选模板且正文未被手改时，
  修改标题会跟随重新渲染 `{{title}}`；
- 占位符：`{{title}}` `{{date}}` `{{time}}` `{{datetime}}` `{{weekday}}`
  （另接受 `{{标题}}` `{{日期}}` `{{时间}}`），未知占位符原样保留；
- 模板读取失败（例如浏览器预览模式）时静默忽略，不影响手动创建。

### 知识图谱（V1.1 M3 增补）

- 入口：侧边栏「知识图谱」（`/graph`）；右上角显示「N 个节点 · M 条连接 · 耗时 ms」；
- 画布交互：滚轮缩放（以指针为中心，0.15×–4×）、拖拽空白平移、拖拽节点固定位置、
  单击选中并高亮其连接、双击打开笔记、`F` 键适应窗口；
- 布局：收敛前每 15 帧自动取景，收敛后停止渲染帧（静态画面不占 CPU），
  数据或筛选变化时重建布局；
- 筛选：分类（含子分类）、标签、孤立节点开关、聚焦当前笔记（1 跳 / 2 跳）；
- 右栏：图例（分类配色 + 未分类灰色，最多 6 项）、选中笔记详情（邻居数、标签、聚焦/打开）、
  操作说明；节点大小 = 可见子图内的邻居数；
- 截断提示：超过 2000 节点或 5000 条连接时按连接度优先保留，并在顶部用琥珀色提示建议先筛选。

### 导入工具（V1.1.2 增补）

- 导入页签新增「导入格式」下拉：自动识别（默认）/ 通用 Markdown / Obsidian 库 / Notion 导出；
- 自动识别：目录内有 `.obsidian/` → Obsidian；出现 `名称 <32 位十六进制>.md` → Notion；
- 两种模式下图片/PDF 等附件会一并复制到 `attachments/YYYY-MM/`，正文引用自动改写；
- 成功提示显示「已导入 N 篇笔记，附 M 个附件（Obsidian/Notion）」。

### 搜索历史与收藏条件（V1.1.2 增补）

- 搜索框下方显示「最近搜索」（最多 6 个 chip，点击恢复条件）与「收藏的搜索」（点击恢复、✕ 删除）；
- 有有效条件时显示「保存当前搜索条件」，弹窗只需填名字（默认取关键词）；
- 历史与收藏按工作区保存在本地，不进入知识库文件，也不随备份带走。

### 拖拽移动分类（V1.1.2 增补）

- 笔记行可拖拽：放到侧边栏分类 → 移动到该分类；放到 Inbox → 移出分类；
- 放置目标高亮（`ring`），松开即执行并提示结果；多选状态下拖动一行会带走整批；
- 自定义 MIME `application/x-pkos-note` 承载 id 数组，非笔记拖拽一律忽略。

### 批量操作（V1.1.2 增补）

- 笔记列表工具条新增「多选」：进入后每行左侧出现勾选框，顶部工具条显示
  「已选 N / 全选 / 清除 / 移动 / 标签 / 删除 / 退出」；
- `Cmd/Ctrl + 点击` 任意行即可切换选择并自动进入多选；多选模式下单击行 = 勾选（不打开笔记）；
- 批量删除为移入回收站（二次确认），批量移动与打标签使用独立对话框。

### 附件管理（V1.1.2 增补）

- 侧边栏「附件」进入 `/attachments`：头部显示「文件数 · 总占用 · 被引用 / 未引用」；
- 列表按 `YYYY-MM` 目录分组，每行显示文件名、体积、修改时间、引用它的笔记（可点击跳转）或「未引用」标记；
- 删除按钮带二次确认；若仍被笔记引用，确认框内列出引用笔记并提示「引用会失效」；

### 拖拽建立层级与排序（V1.2.1 增补，对标语雀）

## 4. 编辑器行为（设计文档 16.5）

| 状态 | 表现 |
| --- | --- |
| 未保存 | 顶栏显示「未保存」 |
| 保存中 | 显示旋转图标「保存中」，串行化避免并发写入 |
| 已保存 | 显示「已保存」，元信息栏显示索引时间 |
| 已保存但索引没跟上 | 显示琥珀色「已保存（检索索引待重建）」+ 悬停看原因（`note_save` 的 `indexWarning`）——正文已写盘、但检索里搜不到这篇，不能在界面上看起来像一切正常 |

### 大纲的两处位置与设置项（V1.3.0 布局调整，Track G1）

- **为什么改**：原来四列并排（分类树 + 列表 + 编辑/预览 + 大纲），在 1440px 以下的窗口里
  正文被挤到只剩一半，长段落阅读很难受；而大纲多数时候只是"看一眼结构"，不值得常驻一列；
- **默认**：大纲与笔记列表**共用中栏**（`[分类树][列表 ⇄ 大纲][编辑|预览]`），三列到底；
  栏头顺序为「〈〈 返回列表」→ 列表树图标 → 「大纲」→「· 笔记标题」→ 标题数量 →
  位置切换按钮；没有标题时沿用原来的 `#` 书写引导；
- **换位置**：两个方向各有一个入口，不会"挪走了找不回来"——
  列表栏里的大纲 →「钉在正文右侧」；正文右侧的大纲 →「改到笔记列表那一栏」；
- **设置页**（「编辑器」区新增两项）：
  - **大纲位置**：`与笔记列表共用一栏`（默认）/ `钉在正文右侧`，下拉即改即存；
  - **选中笔记后自动显示大纲**：默认关，打开后选中笔记即看结构；
- **持久化口径**：位置与自动显示是**工作区级偏好**（写 `settings`，设置页与面板按钮同口径）；
  "这一栏此刻显示列表还是大纲"是**内存态**：不落库，**关掉重开**回到列表；
  应用运行期间**保持当前选择**（连着看几篇笔记时不会被反复重置——真机验过，切笔记不重置）；
- **提交为空**：`outlinePlacement` 只接受 `list` / `side`，未知值保留原值（与 `list_sort` 同口径）；
- **覆盖的口径**（`e2e/app.spec.ts` 步骤 18 / 24 / 27）：默认断言列表栏在、大纲不在 →
  点「显示大纲」→ 断言 `list-pane-outline` 在、列表不在 → 点「〈〈 返回列表」→ 回到列表 →
  「钉在正文右侧」→ 断言大纲回到正文右边 → 收起 / 悬停 / 钉住 → 「改到笔记列表那一栏」→
  大纲回到中栏。

### 界面梳理：去重复、开关归位、折叠与截断（V1.3.0 第二轮，2026-10-15）

一轮把"同一个动作有多个入口"和"控件跑到离它管的东西很远"的地方收干净：

1. **侧边栏开关只剩一个，且不跳位置**：删除顶栏的「切换侧边栏」（与侧边栏自己的收起/展开重复）；
   收起后 44px 图标栏里的「展开」从**顶部挪到底部**，与展开态底栏的「收起」同高——
   两个状态下开关停在同一个位置，点它不用重新找；
2. **大纲开关挪到中栏头部**（原来在编辑器工具栏：工具栏只在打开笔记时才存在，而列表栏一直在）：
   `标题 + 篇数` 靠左（一眼看出"这是哪个范围的几篇"），开关放最右；
   没有选中笔记时置灰（那会儿没有大纲可看）。右侧形态（常驻/贴边/隐藏）随之从
   `NoteEditorPage` 的局部 state 提到 `uiStore`，因为列表栏也要能开这一列；
   **注意**：这一栏显示大纲时栏头归大纲（有「〈〈 返回列表」），开关不在了——回来走那个按钮；
3. **删除侧边栏的「设置」导航项**：右上角那个是唯一入口（顶级动作不该有两个入口）；
4. **分类 / 标签区块可折叠**：点区块标题折叠/展开（`data-testid` 为 `categories-toggle` /
   `tags-toggle`，带 `aria-expanded`）；折叠状态是内存态（与侧边栏折叠一致）；
5. **标题被截断时，条目右侧两个快捷按钮常显**：见「列表条目形态」一节；
6. **修掉一个"行比面板还宽"的布局缺陷**（第 5 条的根因）：Radix `ScrollArea` 会在 Viewport 里
   塞一层 `display: table; min-width: 100%` 的内容 div，table 盒子**按内容撑宽**——
   实测面板 320px 时条目行有 520px，于是标题永远不截断、行右侧的按钮被面板裁掉
   （屏幕上表现为"标题被面板边缘切掉，右边什么都没有"）。`src/components/ui/scroll-area.tsx`
   里用 `[&>div]:!block` 覆盖掉那层 table（内联样式必须用 `!`）；本仓库两处用它
   （笔记列表、侧边栏）都只做竖向滚动，不需要那套横向撑宽。
7. **收起态侧边栏变成图标栏**（对 Codex 桌面端）：导航项一个个摆进去，选中项品牌色底、
   悬停出名字（tooltip），底部仍是「展开侧边栏」。实现上两态**共用 `navItems.ts` 的一份定义**；
   图标栏的选中高亮用 `aria-[current=page]:` 变体做——
   因为 `TooltipTrigger asChild` 合并 props 时会把**函数形式的 `className`** 直接拼成字符串
   （实测 class 里真出现了函数源码，高亮整条失效），所以这里刻意用**纯字符串 className + 属性选择器**。
